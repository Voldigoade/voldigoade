### About

I build and experiment across software development, operating systems, networking, security and privacy.

I like moving between layers: from web and desktop applications to Linux/Unix environments, protocols, automation, system internals and privacy-focused technologies. Most of my projects start with the same question: **how does this actually work?**

### How I like to work

I prefer small, understandable systems over unnecessary complexity. I care about maintainability, privacy, open standards and knowing what a tool is doing instead of treating it as a black box.

I also spend a lot of time trying different operating systems, desktop environments, development stacks and technical workflows simply to understand their trade-offs in practice.
